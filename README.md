## How I Work

I don't start with a tool.

I start with the **business problem**.

**Understand the process → identify repetitive work → define the business logic → design the automation → use AI where it adds real value → connect the required systems → test and improve the workflow**

The goal is not to automate everything.

The goal is to automate the **right work** and solve the actual business problem.
